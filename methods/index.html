01 · construction

Construct the complete survey spine before enrichment

  1. Harmonize ACS and CPS ASEC. Preserve source identities and entity relationships. Record variable renames, unit and period conversions, derived values, missingness and modeling judgments as graph operations.
  2. Allocate survey mass and create the initial support clones. PUF tax detail will enrich clones of the combined survey population. A separate ASEC-only PUF population is not the construction plan.
  3. Assign one Census block to each resulting household. Stable source and clone identities determine the draw, constrained by observed geography. Derive larger geographies from versioned mappings.
  4. Enrich while retaining location. Complete financial, tax-detail, benefit, health, housing and asset inputs with explicit sources and models. Prior wages are excluded. A missing value is not an observed zero.
  5. Evaluate and calibrate the complete population. Measure national, state and district targets on the same records. Calibration changes household weights.
  6. Derive and verify analysis files. Retained records keep their inputs, relationships and locations. Separately refitted compact files need measured approximation tolerances.

For consistent definitions and one set of weights, additive local totals reconcile to national totals. Common source records alone do not guarantee equality between separately calibrated views.

02 · geography

One atomic area determines larger geographies

The corrected native pilot assigns Census blocks after the initial multispine clones, then derives county, tract, PUMA, state and congressional district. Distinct clones can receive distinct blocks within observed source constraints. Later enrichment and analysis views retain the assigned location.

Block assignment supplies modeled detail. It does not establish that block, tract or county analysis is statistically supported. District-level support and calibrated fit remain separate release checks.

The UK follows the same design with nation-specific atomic areas: Output Areas in England, Wales and Scotland, and Data Zones in Northern Ireland. Existing UK area-ladder and supplied-array adapter checks do not establish native integration of the shared graph. The US and UK release path records the country dependencies and remaining validation.

03 · evidence

What has actually passed

Native survey and financial graph. At a 1/1000 source sample, 1,584 ACS/ASEC households and 3,464 people become 3,168 households and 6,928 people after cloning. Cold execution passed on 11 September. Required replay passed on 12 September: all nine prefix and nineteen financial-graph nodes reused their cached results. Four non-manifest exports matched byte for byte; portable manifest content also matched, excluding only timing and cache-hit fields.

The replay took 66.4 minutes and peaked at 10.99 GB RAM. All source, resource, native-input, owned-file and thread checks stayed unchanged, with no unexpected access refusals. This verifies the frozen financial stage at 2ca11c85a, not later source changes. Read the exact replay evidence.

Combined-survey PUF host. The maintained two-route host passes 31 small and two full controls on invented sources. The full case performs 110 fits and 110 applications, cold execution and required replay, with complete population preservation. Known survey Social Security totals supply a ninth predictor; unknown totals use eight without a zero fallback. Native donor-to-survey transfer and conditional-fit quality remain pending. Read the PUF acceptance scope.

Fiscal measurement and dense calibration. Both stages are integrated. All 42 combined stage tests pass; independent dense-calibration review passed 167 selected tests. Measurement uses household-aligned sparse contributions and explicit national/state/district scopes. The existing grouped Adam solver preserves initial zero weights, enforces group limits and refuses a final row-cap overage. It returns schema-8 diagnostics. Numeric bounds do not establish source authority; the host must verify the original sampling references and complete parent. No fully enriched native calibration is accepted yet.

Graph and input diagnostics. Shared graph tests verify storage, exceptional states, replay and isolation from observer mutations. Input reports distinguish source and clone groups, owners, knownness and missing fields. The minimal invented PUF fixture contains 61 of 161 required names; name presence is not evidence of applicability or native completeness.

04 · release

The remaining path to a verified file

Complete native PUF transfer and every applicable model-input producer; run the locked model and national/state/district calibration on that same enriched population; evaluate held-out distributions, geographic support, incumbent comparisons and representative reforms. Increase local size only after smaller checks pass.

Full and compact files then need export/readback, retained-input invariance and actual consumer loading. The dashboard must show their exact candidate and manifest, including target errors, support gaps, weight concentration and pruning effects. Passing component tests cannot substitute for these candidate-specific checks.

The release plan and integration PR track the work. This development evidence informs the composition, support and calibration research questions; it is not a new comparative paper result.
